첫 최소 구현 제안은 P1+P2다. 새 data-only role selector가 SIMULATION→WorkerUserDataDirectory/WorkerCwd, READ_ONLY→ValidatorUserDataDirectory/ValidatorCwd를 반환한다. 기존 14config/15snapshot/11receipt/7descriptor/13snapshot-redaction은 그대로 둔다. Normal units는 global setter/Worker component/GenFilePaths/Process 대신 PURE helper와 normal snapshot/receipt만 사용한다. Native GenFilePaths의 effective root 변경·관측을 이 helper PASS로 주장하지 않는다.

연결된 child launch는 P3-P5의 구체적인 선행 조건이 있어 별도 Master scope가 필요하다. Parent SIMULATION admitted receipt는 executable/SHA·경로·정책을 제공하지만 현 schema에는 child READ_ONLY config path/SHA·original7 declaration을 별도로 등록하는 carrier가 없다. SIMULATION config의 role만 READ_ONLY로 바꾸거나 child origin/plan/configId를 임의 생성하면 raw configSHA/승인 선언 결속을 깨뜨린다. Operator가 **별도의 정상 READ_ONLY config14+7descriptor를 발급·admit**하고 private child-launch registration에서 immutable receipt를 보관해야 한다. 현재 한 process의 global installed startup receipt를 두 역할로 교체하지 않는다.

추천 additive carrier는 WE-M04-OWNED-VALIDATOR-FRONTEND-V1 launch declaration/bundle이며 기존 config schema를 몰래 늘리지 않는다. 저장 위치·producer·registration channel 및 startup flag는 아직 Master 채택 전 제안이다. Bundle에는 READ_ONLY config path/rawSHA, 원문 origin/plan/configId, declared role/capability, admitted frontend contract/선택한 executable identity만 들어간다. Current task/capability/result channel은 simulator/operator의 outstanding sealed task에서 오고 requester/CLI의 임의 manifest·result identity에서 만들지 않는다. Bootstrap schema14·public Snapshot15/Receipt11·R23 private-clone rolecap Trim+OrdinalIgnoreCase·원문 identifier/opaque 정책/UTC 표현을 유지한다. 독립 bundle을 거치지 않은 fallback child declaration을 허용하지 않는다.

PURE immutable launch-plan builder는 parent receipt, 별도 child READ_ONLY receipt, 소유한 current task의 복사된27field projection, 명시된 frontend contract만 받는다. Closed output은 executable/SHA, exact token vector/order/quote encoding, required cwd, selected role UserData, child config path/SHA/original declaration, task path/nonce, 기존 staged path/SHA 및 protected result channel이다. Caller options는 입력으로 받지 않는다. Original child caller/actual usedClone를 이후 편집해도 original plan/fullgraph가 변하지 않아야 한다. 현 ValidatorArguments는 자유 문자열이다. 이번 prospective 정상 fixture는 빈 문자열로 고정한다. 임의 nonempty 옵션을 일반 split으로 소비하거나 reserved operator/task/root flags와 concatenate하지 않는다. 필요한 별도 옵션은 frontend가 실제 지원하는 closed allowlist/token contract를 Master가 먼저 채택해야 한다. Native commandline draft에는7 operator key=value tokens, reference-only savedatafolder token, legacy task/nonce를 정확히 배열로 명시했다. Draft quote-every-token 규약의 literal quote/backslash 처리와 round-trip은 향후 PURE tests로 검증하되 실제 Verse/Unity parser가 같은 값을 받는다는 native 증거는 별도다.

P4에서는 owned plan만 ProcessStartInfo에 투영한다.
