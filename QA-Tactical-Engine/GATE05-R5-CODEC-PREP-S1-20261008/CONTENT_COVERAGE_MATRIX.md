# Actual content와 optional/unknown 범위

Historical source: frozen R4 EngineHostCensus.cs, ContentProfileProvider.ComputeActualContentProfileFingerprint, SHA 09D57DF883576733C2BD4F40FBDE2C616E374FF1EFCCA50A4466C26DD6AA1333. 1-based lines. R5 구현/loaded runtime은 NOT_REVIEWED/UNTESTED. 아래 타입은 논리 codec 모델이며 upstream CLR metadata를 읽었다는 뜻이 아니다.

Disposition은 AVAILABLE(실제 값/bytes/identity 관측), 정상 ABSENT/EMPTY(지원 API가 확정한 부재), OPTIONAL_UNAVAILABLE(명세가 제외할 수 있음을 독립 근거로 승인한 필드), REQUIRED_UNAVAILABLE/UNKNOWN/UNSUPPORTED(필수 material을 결속하지 못함)을 구분한다. 마지막 상태는 trusted fingerprint 성공으로 묵인하지 않는다. 정상 부재를 API 실패와 합치지 않으며 모든 mod/모든 field 지원을 요구하지 않는다.
