# Prospective immutable process evidence contract

This is a future execution plan only. No runner was built, loaded or executed during R13 preparation.

Use a unique directory `runs/<actual-run-id>/` for every process. The final compiled runner and immutable original inputs may be shared read-only; every runtime output must go into its own process directory. Source must not contain a fallback output path into a shared root. A later process must never overwrite any earlier result, reference, central sidecar, raw log, context or dependency observation.

Before any candidate call, copy and bind the original oracle/schema/reference input bytes into that directory, record the exact candidate and runner SHA/size/MVID/CodeView/matching PDB/source, response file, actual resolved SDK/compiler/framework files and dependency references. Record prospective argv/cwd/run ID/culture. Actual process context must add PID/start time and effective culture using observed execution data. The same final runner/original input identity governs both en-US and de-DE processes. Actual R13 API/header/generation/clone/formatter rules must be adopted before this final build and before calls.

After the process exits, preserve combined full stdout/stderr and actual numeric exit from the real process/tool record. A narrated or manually assumed exit is insufficient. Save the exact tool command/cwd/return result as its own file; bind raw/result/context/loaded dependencies/reference outputs and exit to the same actual run ID. A saved runner context is an original sidecar; a summary derived later from logs must be labelled derived and cannot replace an absent original. Pre/post identities and actual loaded managed files must match the prospective pins.

Before starting another process, recursively enumerate **every generated file**, including hidden files, nested folders and newly added central filenames. Do not select output files using a hardcoded prefix/name list. The output inventory must list each relative and absolute path, bytes and SHA256; include input copies, reference byte outputs, full typed/canonical results, returned caller observations, process context, current policy generation/entry diagnostics, actual loaded files, complete raw and exact tool exit proof. The inventory document may exclude itself to avoid a hash cycle, but its own SHA must be externally bound in the enclosing result index. Exclusions must be explicit and cannot include a generated sidecar.

Verify that enumerated paths stay inside the resolved intended process directory, that no file changed between post-run measurement and inventory finalization, and that the file count/path set equals an independent recursive enumeration. This is a read-only check; do not delete/move earlier directories. Finalize the first process's inventory and hash before the second process starts. The second process must use a new non-overlapping directory. Recheck the first process's entire inventory before and after the second process. Include both actual inventories in the terminal manifest. No RUN1 copying into RUN2 or reconstructed original sidecar is permitted.

Compare each process against the independently prospectively selected full typed and byte oracle, then compare matching canonical outputs across the two process inventories. Do not compare only counts/nonempty strings/status or only the latest shared directory. Store explicit candidate-reference bindings, float32 bits/integer widths/ordinal string comparisons, policy/snapshot/generation/context/entry ownership observations and full package-version associations. Numeric counts represent comparisons across views, not unique/native coverage.

If an unexpected normal mismatch, missing file or changed identity occurs, preserve the unmodified candidate/oracle/runner/raw and report the limitation or failure. Do not amend expected values after execution or rebuild/rerun until separately admitted. Terminal graph order is evidence → report → evidence manifest → index → ACK completion binding → COMPLETION last; initial ACK and pending index remain immutable. Actual direct Master delivery is recorded separately after the one terminal send.

Old R12 RUN1's three absent central sidecars and derived context remain historical qualifications. This future contract neither restores those files nor certifies the old producer chronology. Standalone cache core proof remains a unit result; native actual profile/cache hit/operator authority requires separate admitted evidence.
