# Package Validation

- Original copies preserve exact source bytes.
- Generated documents are UTF-8 and nonempty.
- DISPATCHER_STATE.json parsed; automation/bootstrap disabled; queued work NOT_SENT.
- Local source/SRS/candidate/evidence inspection remains pending.
- C correction/ADR acceptance guards present; original report bytes are not relabeled or rewritten.
- Hash inventory covers every package member except the inventory itself; archive CRC/inventory checked after creation.
- No Work Order submitted; no scheduler configured; no Production candidate altered.

Validation is of the handoff package, not software/QA replay.
