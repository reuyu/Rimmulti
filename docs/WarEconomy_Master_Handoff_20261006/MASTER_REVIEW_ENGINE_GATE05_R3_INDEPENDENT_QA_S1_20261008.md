## 채택한 해석 보완

- SIMULATION proposal operation과 READ_ONLY validator role은 각각 결속해야 한다. 원래 grant를 READ_ONLY로 바꾸거나 equality를 삭제해 fixture를 통과시키는 것을 해결로 인정하지 않는다. R3 정상 mode 회귀는 실제 게임 실행이 아니라 독립 source 추적으로 확인됐다.
- 기존 census의 index/tile/parent/faction context와 실제 semantic manifest 검사, Promote의 current authority/grant/generation/epoch/profile/live census/staged SHA 재검사는 존재한다. 이를 없는 것으로 서술하거나 Complete 공백을 최종 canonical promotion 성공/우회로 확대하지 않는다. 부족한 것은 admitted 안정 target mapping과 역할별 complete context 증명이다.
- Cache invalidation은 존재한다. Admitted content lifetime과 재검증/independent actual profile의 충분한 증거가 필요하다. R3는 실제 game dependency를 참조하므로 전부 game stub이라고 단정하지 않는다.
- 제출32 PASS는 metadata4,reflection/handler/file IO26,OS child1,schema constant1이며 native semantic normal flow0이다. Producer의 GENUINE labels나 cryptographic 표현은 실제 source/raw의 범위를 넘겨 채택하지 않는다.
- 실제 candidate/manifest/PDB/source match와 보고서 표4 SHA/2size 오류를 분리한다. Completion aliases는 동일 task를 식별하지만 standard fields/roles/absolute paths와 실행 전 provenance를 대체하지 않는다.
- Original Steam launch와 RuntimeCopy label을 분리한다. Loader/numeric exit/isolated userdata/mod/new loaded candidate/profile/census가 미관측이며 원인 UNKNOWN이다. 실제 사용자 save 변경이나 DRM 차단을 추정하지 않는다. Installed actor/cause UNKNOWN/OPEN 유지.

MD126 public request/equivalent file channel/normal result-after-exit 허용, MD129 relevant state 철회와 clean re-admission, MD130 지원 material typed content, MD131 안전 final replacement, MD132 제한된 V4 scope를 유지한다. All-Def serialization, blanket sort 금지, owner/discardability/PlayerGlobal/physical split을 새로 채택하지 않는다. QA 우선순위 의견은 기존 defect severity/closure를 자동 변경하지 않는다.
