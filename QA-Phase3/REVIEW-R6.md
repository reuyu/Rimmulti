## 범위와 실제 테스트 시 주의할 기대 결과

- 롤백 테스트는 원본 실행기와 엔진 API 형태의 실패 주입 대역을 사용했다. 실제 Unity 콜백/모드 조합과 UI 표시는 아래 수동 검증에서 확인한다. 모든 엔진 부작용의 100% 복구를 증명한 것은 아니다.
- 불완전 복구 표시는 ErrorMessage 문자열이다. 자동 재동기화 기능이 완료됐다는 뜻은 아니다. 발생하면 해당 테스트를 실패로 기록하고 로그와 세이브 사본을 보존한다.
- 디버그 영지 양도는 로컬 실행기를 직접 호출한다. 서버가 결과를 수신해도 Pending 거래가 없어 무시하는 로그가 나올 수 있다. 이 동작으로 서버 소유권 커밋을 합격 처리하지 않는다.
- NPC 자동 승인은 대기창이 빠르게 닫히므로 취소 인터랙션과 분리한다. 수동 취소에는 서버에 등록된 온라인 영주가 응답을 보류하는 환경이 필요하다.
- 방문 승인 후 실제 전술 맵 로딩은 현재 TODO다. History 잔상 렌더링도 현재 체크리스트의 기대 결과에 포함하지 않는다.
- BFS 판정은 인접 관계 2단계 기준이다. 실제 월드의 경계 타일 UI 검증은 아직 수행하지 않았다.
